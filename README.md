# Power-BI-Logistics-Dashboard
Layihənin Məqsədi: Şirkətin xam və nizamsız satış və nəqliyyat məlumatlarını təmizləmək, relyasiyalı data modeli qurmaq və rəhbərlik üçün interaktiv idarəetmə paneli (Dashboard) hazırlamaq.  
 ETL və Data Cleaning (Power Query): Mətnlərin standartlaşdırılması, boş xanaların doldurulması, təkrar dataların silinməsi, regional tarix xətalarının düzəldilməsi və yeni "Marşrut Qeydi" sütununun yaradılması.  
 Data Modeling: Ulduz sxemi (Star Schema) strukturunun qurulması və DAX ilə müstəqil Təqvim cədvəlinin (⁠Dim_Calendar⁠) əlavə edilməsi.  
 DAX Hesablamaları: Ümumi daşıma gəliri, maya dəyəri, xalis mənfəət, mənfəət marjası, həvəsləndirici endirim sütunu və gözlənilən çatdırılma tarixi kimi peşəkar metriklərin hesablanması.  
 Dashboard və Vizualizasiya: KPI kartları, performans matrisi, zaman trendi xətti qrafiki, Top 5 müştəri qrafiki və dinamik slicer-lərin tətbiqi.
